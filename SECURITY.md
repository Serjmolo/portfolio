# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by emailing **aidesignwarrior@gmail.com**.

Include as much detail as possible: steps to reproduce, potential impact, and any suggested fixes.

I will respond within 48 hours and work to address the issue promptly.

## Scope

This is a static personal portfolio site with no backend or user data. Applicable issues include:
- Malicious third-party dependencies
- Content injection vulnerabilities
- Misconfigured hosting or headers

Issues related to third-party services (GitHub Pages infrastructure) should be reported directly to GitHub.
