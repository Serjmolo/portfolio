# DSGN WARRIOR — Sergey Golosov

Portfolio site for Sergey Golosov, Moscow-based art director with 10 years of experience in web, product and branding design.

**Live:** [serjmolo.github.io](https://serjmolo.github.io) *(GitHub Pages)*

---

## Stack

- Plain HTML / CSS / JavaScript — no build tools
- Three.js — interactive eye canvas in the hero
- Deployed via GitHub Pages

## Fonts

- **TT Neoris Trial** (Regular, Medium) — navigation, badges, labels
- **TT Ramillas Trial** (Regular, Italic) — headings, bio text

Fonts are self-hosted in `assets/fonts/`.

## Structure

```
/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── main.js        — animations, custom cursor, smooth scroll
│   └── eye.js         — Three.js hero canvas
├── assets/
│   ├── fonts/
│   └── images/        — cover images, logo, SVG icons
```
